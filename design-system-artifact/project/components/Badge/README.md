# Badge

A small label for a status, role or attribute: 11/14 at 500 in a `radius-sm` box.

## The consumer provides
- `children` (text, optionally an icon) and `variant`: `default` (primary fill), `secondary`, `destructive`, `outline`, `campus` and `subject` (muted fill, muted-foreground text), `success` and `warning` (outline and text in the status colour).

## Rules
- Badges are not buttons. Status badges always carry a word.
