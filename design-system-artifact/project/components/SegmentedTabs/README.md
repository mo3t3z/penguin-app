# SegmentedTabs

Equal-width text tabs that switch views in place, over a `divider` rule.

## The consumer provides
- `tabs` (key and label), `value` and `onChange`.

## Rules
- 44 high, `label` text in `muted-foreground`; the selected tab is `foreground` at 600 with a 2px `primary` underline.

Hand-written from src/components/navigation/segmented-tabs.tsx.
