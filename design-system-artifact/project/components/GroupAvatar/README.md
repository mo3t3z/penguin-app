# GroupAvatar

A group shown by its initials in a rounded square, so it never looks like a student.

## The consumer provides
- `name` and `size`: `lg` (48, `radius-md`) or `xl` (96, `radius-lg`).

## Rules
- Never a circle. Fill `muted` or `accent`, chosen from the name.
